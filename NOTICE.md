# Credits and licensing status

## Project code

This repository publishes the SubMental prototype and its documentation. No repository-wide software license has been selected. Public visibility does not itself declare a particular software license.

## Historical NASA material

The source dataset is NASA’s **uncorrected Apollo 11 Technical Air-to-Ground transcript**, with source context at:

- https://www.nasa.gov/wp-content/uploads/static/history/alsj/a11/a11transcript_tec.html
- https://www.nasa.gov/wp-content/uploads/static/history/alsj/a11/a11trans.html

The portrait is NASA image S64-31452, credited through:

- https://www.nasa.gov/people/neil-a-armstrong/

Historical mission footage is credited to **NASA / Apollo Flight Journal**. Exact archive pages, source media URLs and extraction positions are listed in `data/camera/catalog.json`.

- https://www.apollojournals.org/afj/ap11fj/videoindex.html
- https://www.apollojournals.org/afj/ap11fj/09day3-entering-eagle.html
- https://www.apollojournals.org/afj/ap11fj/23day7-tv-food-prep.html

The archive’s source and usage notes should be consulted for reuse. NASA footage, the Flight Journal’s annotations/commentary and other third-party material should not be assumed to share one blanket license. The corrected Flight Journal transcript is not the copied text dataset for this app.

No NASA affiliation, approval or endorsement is claimed. The NASA portrait and historical media do not endorse SubMental. Simulated pulse, blood pressure, tension and personal-baseline values are not Armstrong’s medical records.

## Research, software and models

Linked papers retain their publishers’ and authors’ terms. Dependencies and model weights retain their own licenses and terms; they are not relicensed by this repository. Model weights are not bundled. See `docs/RESEARCH.md`, package metadata and the model providers’ documentation.

## Generated analysis

The repository retains actual local model responses, reviewed presentation material and explicit simulations for a research demonstration. Their inclusion does not establish clinical accuracy or operational suitability.
